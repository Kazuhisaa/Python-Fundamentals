# 🐍 Python Fundamentals: No Vibe Coding Allowed

Welcome to my Python learning repository. This isn't a place where I just copy-paste code from tutorials, run it, see that it works, and call it a day. 

This repository tracks my journey to **genuinely understand Python from the ground up**, breaking down concepts, making mistakes, and writing code line-by-line to build real muscle memory as a developer.

---

## 🚫 What is "No Vibe Coding"?

**Vibe Coding** is when you write code based on "vibes" or feelings—relying too much on AI tools, stack overflow, or tutorials to do the heavy lifting without actually understanding *why* the code works or *how* the logic flows. 

### My Rule for This Repo:
* **No Blind Copy-Pasting:** Every line of code here is written or analyzed by me.
* **Understand the Mechanics:** If I use a function, a loop, or a data structure, I must be able to explain how it manages memory or execution under the hood.
* **Break & Fix:** I intentionally break the code to understand the error messages. Debugging is where real growth happens.

---

## 🎯 Core Focus Areas

Here are the fundamentals I am mastering to strengthen my logical thinking and coding foundation:

- [ ] **Syntax & Control Flow:** Conditionals, loops (`for`, `while`), and error handling (`try-except`).
- [ ] **Data Structures:** Deep dive into Lists, Tuples, Dictionaries, and Sets (and when to use which).
- [ ] **Functions & Scope:** Writing reusable code, understanding positional vs. keyword arguments, and local vs. global scope.
- [ ] **File I/O:** Reading, writing, and managing external files correctly.
- [ ] **Object-Oriented Programming (OOP):** Classes, objects, inheritance, and encapsulation (moving past just procedural scripts).

---

## 🛠️ How I Practice

1. **Daily Commits:** Small, consistent updates rather than massive, unchecked code dumps.
2. **Comments on "Why":** You'll see comments in my scripts explaining *why* a certain approach was taken, not just *what* the code does.
3. **Problem Solving:** Applying Python to algorithmic challenges to sharpen problem-solving skills, not just syntax familiarity.
